### 核心框架
- **React 18** + **Next.js 14**（App Router）
- **TypeScript**（严格模式）
- **Tailwind CSS** + **postcss** + **autoprefixer**

### 布局模式切换（H5 / Web）
- **方案**：自定义 React Context（`LayoutProvider`）存储 `mode`（`'mobile'` / `'web'`）
- **响应式策略**：Tailwind 断点基础上叠加条件渲染（`mode === 'mobile' ? 单列 : 网格`），切换时改变布局容器类与组件排列方式
- **持久化**：localStorage 保存用户偏好

### 主题换肤（纯净风 / 科技风）
- **方案**：CSS 变量 + `data-theme` 属性（`<html data-theme="pure|tech">`）
- **主题变量**：颜色、阴影、圆角、背景渐变、字体等通过 Tailwind 配置文件扩展，并用 CSS 变量覆盖
- **切换**：React Context（`ThemeProvider`）动态修改 `data-theme` 并存储至 localStorage

### UI 组件库
- **基础组件**：**Radix UI**（无样式、无障碍） + **Headless UI**（菜单、弹窗、选项卡）
- **样式覆盖**：用 Tailwind 类名统一风格，不依赖第三方样式
- **图标**：**Lucide React**（轻量、可定制）

### 状态管理
- **客户端状态**：**Zustand**（简单、体积小）或 **Jotai**（原子化，适合主题/布局这类全局状态）
- **服务端状态**：**TanStack Query**（数据获取、缓存、同步）

### 动画与微交互
- **CSS 动画**：Tailwind 内置 `animate-*` + 自定义关键帧
- **复杂交互动画**：**Framer Motion**（页面切换、拖拽、手势，按需引入）
- **滚动动画**：**AOS** 或 **ScrollReveal**，或直接使用 Intersection Observer + Framer Motion

### 路由与导航
- **Next.js 内置 App Router**（文件系统路由）
- **动态加载**：`next/dynamic` 配合 React.lazy 实现代码分割

### 样式与设计系统
- **设计令牌**：Tailwind 配置文件定义 `theme.extend`（间距、断点、阴影、渐变、字体族）
- **字体**：Google Fonts（如 Inter、SF Pro）通过 `next/font` 加载
- **暗色/亮色**：由主题变量控制，不依赖系统暗色模式

### 工具库
- **类型安全**：`zod` 用于运行时数据校验（API 响应、表单）
- **日期处理**：`date-fns`（轻量）
- **HTTP 请求**：原生 `fetch` + TanStack Query，封装统一错误处理

### 测试
- **单元/组件测试**：**Vitest** + **React Testing Library**
- **E2E 测试**：**Playwright**

### 代码规范
- **代码检查**：**ESLint**（Next.js 官方配置 + 自定义规则）
- **格式化**：**Prettier**
- **Git 钩子**：**Husky** + **lint-staged**
- **提交规范**：**Commitizen** + **commitlint**

### 性能优化
- **图片**：Next.js `Image` 组件 + 本地图片自动优化
- **字体**：`next/font` 实现字体自托管与预加载
- **代码拆分**：动态导入非首屏组件
- **SEO**：Next.js 元数据 API（`generateMetadata`）

### 部署
- **平台**：自托管 Node.js
- **环境变量**：`.env.local` 管理敏感信息
