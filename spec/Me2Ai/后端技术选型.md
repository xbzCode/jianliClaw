### 后端技术选型

#### 整体架构
- **API 网关层**：NestJS +TypeScript
- **微服务通信**：gRPC / HTTP REST（初期 REST，按需升级）  

---

#### 1. 用户服务
- **框架**：NestJS + TypeScript  
- **数据库**：PostgreSQL 15+（主库）  
- **ORM**：TypeORM（或 Prisma）  
- **认证**：Passport.js + JWT（@nestjs/jwt, @nestjs/passport）  
- **密码加密**：bcrypt  
- **权限**：CASL（基于能力的访问控制）  
- **缓存**：Redis（会话、黑名单）

---

#### 2. 简历服务
- **框架**：NestJS  
- **文件存储**：AWS S3 / MinIO（本地开发用 MinIO）  
- **文件上传**：@nestjs/platform-express + multer  
- **文本解析**：  
  - 基础解析：Python `pdfplumber` / `docx2txt`（通过 HTTP 调用 Python 微服务）  
  - 结构化存储：JSON 字段 + 全文检索（PostgreSQL 的 tsvector / pg_search）  
- **版本管理**：数据库记录版本号，S3 存储历史文件  
- **PDF 生成**：Puppeteer（HTML → PDF）或 Python `weasyprint`

---

#### 3. AI 网关
**3.1 统一封装层（Nest）**  
- **HTTP 客户端**：@nestjs/axios（封装 Python 服务调用）  
- **限流**：@nestjs/throttler（全局限流 + 按用户/接口精细化）  
- **重试/降级**：自定义拦截器 + 断路器（resilience4js / 自实现）  
- **调用日志**：记录请求/响应、耗时、token 数（使用 Winston 结构化日志）

**3.2 AI 微服务（Python FastAPI）**  
- **框架**：FastAPI + Uvicorn  
- **依赖管理**：Poetry  
- **LLM 调用**：OpenAI API（主）、本地模型备用（vLLM / Ollama）  
- **Embedding 模型**：OpenAI `text-embedding-ada-002` 或 `sentence-transformers/all-MiniLM-L6-v2`  
- **向量数据库**：pgvector（PostgreSQL 扩展）或 Qdrant（轻量）  
- **Prompt 管理**：YAML 配置文件 + 模板引擎（Jinja2）  
- **任务队列**：Celery + Redis（处理长时间生成任务，如批量简历改写）  
- **模型服务**：  
  - 结构化提取：结合 LangChain + 自定义输出解析器  
  - 相似度计算：numpy / scikit-learn（规则权重 + 向量余弦）

---

#### 4. 日志与监控
- **应用日志**：Winston（Nest） + Python logging（FastAPI）  
- **日志收集**：ELK（Elasticsearch + Logstash + Kibana）或 Loki + Grafana  
- **性能监控**：Prometheus + Grafana（暴露 `/metrics` 端点）  
- **链路追踪**：OpenTelemetry + Jaeger  
- **告警**：AlertManager（结合飞书/钉钉 Webhook）

---

#### 5. 基础设施与运维
- **数据库迁移**：TypeORM CLI / Prisma Migrate  
- **API 文档**：Swagger（NestJS） + FastAPI 自带 Swagger  
- **环境配置**：dotenv + NestJS ConfigModule  
- **CI/CD**：GitHub Actions / GitLab CI  
- **容器编排**：Kubernetes（生产）  
- **反向代理**：Nginx（SSL、负载均衡）

---

#### 6. 安全与合规
- **输入校验**：class-validator + class-transformer  
- **SQL 注入防护**：ORM 参数化查询  
- **XSS 防护**：Helmet + 模板输出转义  
- **敏感信息**：AWS Secrets Manager / Vault  
- **数据脱敏**：日志自动脱敏（手机号、邮箱）
