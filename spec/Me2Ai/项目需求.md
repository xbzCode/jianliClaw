#### 产品定位
**“简历智伴”** 一款面向求职者的AI简历优化助手，通过解析职位描述，帮助用户生成高匹配度的简历内容与沟通话术，提升求职效率。后续可扩展模拟面试等辅助功能。

#### 用户角色
- **普通用户**：可使用核心简历优化功能，管理个人简历
- **高级用户**（未来）：享受更多模板、无限次生成、面试模拟等增值服务

### 三、Web端功能模块

#### 1. 首页
- 产品价值主张（3秒抓住痛点）
- 功能亮点展示（匹配度分析、一键生成、话术库）
- 使用流程示意（图文/短视频）
- 典型用户案例/效果对比
- CTA（开始使用 / 上传简历）

#### 2. 简历工作台（核心模块）
**2.1 职位解析与匹配**
- 输入职位描述（支持文本粘贴/URL抓取）
- 自动提取关键要求（技能、经验、学历等）
- 上传简历（支持PDF/Word/在线编辑），展示**匹配度仪表盘**（整体匹配度、关键词缺失、经验对齐建议）

**2.2 简历生成与编辑**
- **生成策略**：
  - 智能改写：针对目标JD，突出匹配经验
  - 结构调整：根据JD要求推荐模块排序
- **双栏预览**：左侧编辑区（Markdown/富文本），右侧实时简历预览
- **模板选择**：提供3-5种简洁专业模板，一键切换，保持内容不变
- **版本管理**：支持保存为“新版本”，不覆盖原始简历

**2.3 衍生工具**
- **打招呼语生成**：
  - 输入对方称呼、职位来源（如BOSS直聘、LinkedIn）
  - 生成多种风格（专业/简洁/热情）
  - 一键复制，附带使用建议（如“建议补充一句个人优势”）

#### 3. 个人中心
- **我的简历库**：
  - 展示所有简历（原始版本、优化版本）
  - 支持上传、下载、重命名、删除、设为默认
- **账户设置**：
  - 头像、昵称、密码修改
  - 模型偏好（默认“平衡模式”，可选“精准匹配模式”调用更强模型）
- **数据管理**：导出个人所有数据（JSON格式，符合GDPR）

#### 4. 系统设置（仅管理员/开发者可见）
- API密钥配置（用于自部署场景）
- 模型参数调节（temperature、max_tokens等）
- 日志查看（操作日志、模型调用日志）


### 四、后端服务架构（Node + Nest + Python）

#### 整体架构分层
```
[前端] → [Nest API网关] → [业务模块] → [AI网关] → [模型层]
                       ↘ [文件/用户服务]
```

#### 1. 用户服务（Nest + TypeORM）
- 登录/注册（JWT，支持邮箱/手机号）
- 用户信息管理
- 权限控制（普通用户/管理员）

#### 2. 简历服务（Nest + 文件存储）
- 简历上传/解析（文本提取，可调用Python服务）
- 简历CRUD、版本管理
- 模板存储与渲染（可生成HTML/PDF）

#### 3. AI网关（Nest + Python FastAPI 混合）
**3.1 分析服务（Python）**
- JD解析：提取结构化要求（使用大模型+正则兜底）
- 匹配度计算：基于语义相似度（Embedding + 规则权重）

**3.2 生成服务（Python）**
- 简历改写：根据JD和用户简历生成新内容（Prompt工程）
- 招呼语生成：模板+个性化组合
- 面试问答生成（预留）

**3.3 统一调用层（Nest）**
- 封装所有AI调用，统一日志、限流、重试、降级（如模型不可用时返回预设模板）
- 记录每次调用耗时、token消耗（为后续计费做准备）

#### 4. 日志与监控（Nest）
- 操作日志（用户行为）
- 系统日志（错误、性能）
- AI调用审计（用于调试和成本分析）
