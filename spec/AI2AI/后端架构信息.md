## 各个模块的外部特性

### 用户认证模块 (`modules/auth/`)

#### 外部接口
- `POST /auth/login`：用户登录，返回JWT token
- `POST /auth/register`：用户注册
- `POST /auth/logout`：用户登出（token加入黑名单）
- `GET /auth/profile`：获取当前用户信息
- `PUT /auth/profile`：更新用户信息
- `POST /auth/refresh`：刷新token（预留）

#### 技术特性
- **认证方案**：Passport.js + JWT
- **Token存储**：前端sessionStorage，Access Token短期有效（2小时）
- **密码加密**：bcrypt
- **权限控制**：CASL（基于能力的访问控制）
- **缓存**：Redis存储会话和token黑名单

#### 依赖
- PostgreSQL（用户数据）
- Redis（会话缓存）

### 简历模块 (`modules/resume/`)

#### 外部接口
- `POST /resume/upload`：上传简历文件（PDF/Word）
- `GET /resume`：获取用户简历列表
- `GET /resume/:id`：获取单个简历详情
- `POST /resume`：创建新简历（在线编辑）
- `PUT /resume/:id`：更新简历内容
- `DELETE /resume/:id`：删除简历
- `POST /resume/:id/version`：创建新版本
- `GET /resume/:id/export`：导出PDF
- `GET /resume/:id/parse`：解析简历文件（调用Python服务）

#### 技术特性
- **文件存储**：MinIO（S3协议兼容）
- **文件上传**：@nestjs/platform-express + multer
- **文本解析**：通过HTTP调用Python服务的`pdfplumber`/`python-docx`
- **在线编辑存储**：简历内容以JSON格式存储于数据库
- **版本管理**：数据库记录版本号，MinIO存储历史文件
- **PDF生成**：Puppeteer抓取前端渲染页面生成PDF

#### 依赖
- PostgreSQL（简历元数据和JSON内容）
- MinIO（文件存储）
- Python AI服务（简历解析）

### AI模块（统一封装层） (`modules/ai/`)

#### 外部接口
- `POST /ai/analyze-jd`：分析职位描述，返回结构化要求
- `POST /ai/optimize-resume`：根据JD优化简历内容
- `POST /ai/generate-greeting`：生成打招呼语
- `GET /ai/stream`：流式输出接口（SSE）
- `GET /ai/tools`：获取可用工具列表（预留）

#### 子模块特性

##### 模型网关 (`gateways/`)
- **统一调用**：封装OpenAI API调用
- **流式输出**：支持SSE流式返回
- **缓存优化**：Redis缓存相同请求结果
- **成本统计**：记录Token消耗
- **降级策略**：断路器（opossum）实现重试和降级

##### 工具模块 (`tools/`)
- **MVP内置工具**：
  1. `resume_parser`：简历文件解析（调用Python服务）
  2. `jd_analyzer`：职位描述分析（LLM结构化提取）
  3. `resume_optimizer`：简历内容改写（LLM生成）
- **工具注册**：硬编码注册，预留动态注册接口
- **协议适配**：内置工具直接调用，预留MCP协议支持

##### 提示词模块 (`prompts/`)
- **模板管理**：YAML文件存储 + 版本控制
- **动态组装**：系统提示 + 任务提示 + 变量注入
- **变量来源**：用户信息、简历内容、JD内容
- **模板引擎**：Jinja2（Python）/ Mustache（Node）

##### 记忆模块 (`memory/`)
- **短期记忆**：Redis存储最近N轮对话
- **存储结构**：Redis List，TTL + LRU淘汰
- **接口**：按sessionId管理对话上下文

##### 安全过滤模块 (`security/`)
- **输入过滤**：敏感词列表 + 长度限制
- **输出审核**：预留有害内容检测
- **操作审计**：日志记录所有AI调用

#### 依赖
- Redis（缓存、记忆存储）
- Python AI服务（实际AI处理）
- OpenAI API（或本地模型）

### 日志模块 (`modules/logging/`)

#### 外部接口
- `GET /logs/operations`：获取操作日志（管理员）
- `GET /logs/system`：获取系统日志（管理员）
- `GET /logs/ai`：获取AI调用审计日志（管理员）

#### 技术特性
- **日志收集**：Winston结构化日志
- **存储**：PostgreSQL日志表 + Loki（可选）
- **监控**：Prometheus指标暴露 `/metrics`
- **告警**：AlertManager集成飞书/钉钉Webhook

#### 依赖
- PostgreSQL（日志存储）
- Loki + Grafana（日志可视化，可选）
- Prometheus + Grafana（性能监控，可选）

### 共享模块 (`modules/shared/`)

#### 数据库模块 (`database/`)
- **ORM**：Prisma（类型安全、迁移体验佳）
- **向量扩展**：pgvector（PostgreSQL扩展，用于Embedding存储）
- **连接池**：配置优化

#### 文件存储模块 (`storage/`)
- **客户端**：MinIO客户端封装
- **功能**：文件上传、下载、删除、生成预签名URL
- **兼容性**：S3协议，便于迁移到AWS S3

#### 缓存模块 (`cache/`)
- **客户端**：Redis客户端封装
- **功能**：键值存储、发布订阅、列表操作
- **使用场景**：会话缓存、AI结果缓存、限流计数

#### 配置模块 (`config/`)
- **环境变量**：dotenv + NestJS ConfigModule
- **配置文件**：YAML/JSON配置文件支持
- **验证**：环境变量验证和默认值

### Python AI服务 (`ai-service/`)

#### 外部接口（供NestJS调用）
- `POST /analyze-jd`：解析职位描述，返回结构化数据
- `POST /optimize-resume`：优化简历内容
- `POST /generate-greeting`：生成打招呼语
- `POST /calculate-match`：计算简历与JD匹配度

#### 技术特性
- **框架**：FastAPI + Uvicorn
- **生产部署**：Gunicorn + Uvicorn workers
- **LLM调用**：OpenAI API为主，本地模型备用（vLLM/Ollama）
- **Embedding模型**：OpenAI `text-embedding-3-small` 或 `sentence-transformers/all-MiniLM-L6-v2`
- **向量数据库**：pgvector（复用PostgreSQL）
- **Prompt管理**：YAML配置文件 + Jinja2模板引擎
- **结构化提取**：LangChain + 自定义输出解析器
- **相似度计算**：numpy/scikit-learn（规则权重 + 向量余弦）

#### 依赖
- PostgreSQL（含pgvector扩展）
- OpenAI API密钥
- Python依赖：pdfplumber, python-docx, langchain等

## 基础设施与运维

### 数据库
- **PostgreSQL 15+**：主数据库，含pgvector扩展
- **Redis 7**：缓存、会话、消息队列

### 文件存储
- **MinIO**：本地S3兼容对象存储

### 容器化
- **Docker**：每个服务独立容器
- **Docker Compose**：开发环境编排

### 监控与日志
- **应用日志**：Winston（Nest） + Python logging
- **日志收集**：Loki + Grafana（轻量）
- **性能监控**：Prometheus + Grafana
- **链路追踪**：OpenTelemetry + Jaeger（按需）

### 安全与合规
- **输入校验**：class-validator + class-transformer
- **SQL注入防护**：Prisma参数化查询
- **XSS防护**：Helmet + 模板输出转义
- **数据脱敏**：日志自动脱敏（手机号、邮箱）

## 模块依赖关系

```

    ↓

    ↓                    ↓
[简历模块] → [文件存储] → MinIO
    ↓
[AI模块] → [Python AI服务] → OpenAI API
    ↓        ↓        ↓
[工具模块] [提示词] [Embedding] → pgvector
    ↓
[记忆模块] → Redis
    ↓
[日志模块] → PostgreSQL/Loki
```
