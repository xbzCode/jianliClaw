# 协议和数据

## 前后端通信协议

### 基础规范
- **协议**：RESTful API over HTTP/HTTPS
- **数据格式**：JSON（请求/响应体）
- **认证**：JWT Bearer Token
- **Token存储**：前端sessionStorage，请求头 `Authorization: Bearer <token>`
- **API版本**：URL路径中包含版本号，如 `/api/v1/...`
- **错误处理**：统一错误响应格式

### 错误响应格式
```json
{
  "statusCode": number,
  "message": string,
  "error": string,
  "timestamp": string,
  "path": string
}
```

### 分页响应格式
```json
{
  "data": Array<T>,
  "meta": {
    "total": number,
    "page": number,
    "limit": number,
    "totalPages": number
  }
}
```

## 简历相关协议

### 简历数据结构
```typescript
interface Resume {
  id: string;
  userId: string;
  title: string;
  description?: string;
  content: ResumeContent;      // JSON格式的简历内容
  fileUrl?: string;            // 上传的原始文件URL
  fileType?: 'pdf' | 'docx' | 'json';
  isDefault: boolean;
  version: number;
  tags: string[];
  createdAt: string;
  updatedAt: string;
}

interface ResumeContent {
  // 基础信息
  basicInfo: {
    name: string;
    email: string;
    phone: string;
    location?: string;
    portfolio?: string;
    linkedin?: string;
    github?: string;
  };
  
  // 工作经历
  workExperience: Array<{
    id: string;
    company: string;
    position: string;
    location?: string;
    startDate: string;  // YYYY-MM
    endDate?: string;   // YYYY-MM 或 "至今"
    description: string;
    achievements?: string[];
    skills?: string[];
  }>;
  
  // 教育背景
  education: Array<{
    id: string;
    school: string;
    degree: string;
    major?: string;
    location?: string;
    startDate: string;
    endDate?: string;
    gpa?: string;
    description?: string;
  }>;
  
  // 技能
  skills: Array<{
    category: string;
    items: string[];
    level?: number;  // 1-5
  }>;
  
  // 项目经历
  projects: Array<{
    id: string;
    name: string;
    role: string;
    description: string;
    technologies: string[];
    startDate: string;
    endDate?: string;
    link?: string;
  }>;
  
  // 证书
  certifications: Array<{
    name: string;
    issuer: string;
    date: string;
    link?: string;
  }>;
  
  // 语言
  languages: Array<{
    language: string;
    proficiency: 'native' | 'fluent' | 'intermediate' | 'basic';
  }>;
  
  // 自定义模块
  customSections: Array<{
    title: string;
    items: Array<{
      title: string;
      description: string;
      date?: string;
    }>;
  }>;
}
```

### 获取简历列表
**请求** `GET /api/v1/resumes`
**Query Parameters**:
- `page`?: number (default: 1)
- `limit`?: number (default: 20)
- `search`?: string
- `tags`?: string[] (逗号分隔)

**响应** `200 OK`
```json
{
  "data": Resume[],
  "meta": {
    "total": number,
    "page": number,
    "limit": number,
    "totalPages": number
  }
}
```

### 获取单个简历
**请求** `GET /api/v1/resumes/:id`
**响应** `200 OK`
```json
Resume
```

### 创建简历（在线编辑）
**请求** `POST /api/v1/resumes`
```json
{
  "title": "string",
  "description": "string",     // 可选
  "content": ResumeContent,    // JSON格式
  "tags": string[],            // 可选
  "isDefault": boolean         // 可选
}
```

**响应** `201 Created`
```json
Resume
```

### 更新简历内容
**请求** `PUT /api/v1/resumes/:id`
```json
{
  "title": "string",           // 可选
  "description": "string",     // 可选
  "content": ResumeContent,    // 可选
  "tags": string[],            // 可选
  "isDefault": boolean         // 可选
}
```

**响应** `200 OK`
```json
Resume
```

### 上传简历文件
**请求** `POST /api/v1/resumes/upload`
**Content-Type**: `multipart/form-data`
**Form Data**:
- `file`: File (PDF/DOCX)
- `title`: string (可选，默认使用文件名)
- `tags`: string[] (可选)

**响应** `201 Created`
```json
{
  "resume": Resume,
  "parsedContent": ResumeContent  // 解析后的内容
}
```

### 创建新版本
**请求** `POST /api/v1/resumes/:id/version`
```json
{
  "content": ResumeContent,    // 新版本内容
  "note": "string"             // 版本说明（可选）
}
```

**响应** `201 Created`
```json
Resume  // 新版本简历
```

### 导出PDF
**请求** `GET /api/v1/resumes/:id/export`
**Query Parameters**:
- `template`?: string (模板名称)

**响应** `200 OK`
- **Content-Type**: `application/pdf`
- **Content-Disposition**: `attachment; filename="resume.pdf"`

## AI相关协议

### 职位描述分析
**请求** `POST /api/v1/ai/analyze-jd`
```json
{
  "jdText": "string",          // 职位描述文本
  "options": {                 // 可选
    "extractStructured": boolean,  // 是否提取结构化数据
    "language": "zh" | "en"        // 语言
  }
}
```

**响应** `200 OK`
```json
{
  "structured": {
    "jobTitle": string,
    "company": string,
    "location": string,
    "salaryRange": {
      "min": number,
      "max": number,
      "currency": string
    },
    "requirements": {
      "skills": string[],
      "experience": {
        "years": number,
        "level": "junior" | "mid" | "senior"
      },
      "education": string[],
      "certifications": string[]
    },
    "responsibilities": string[],
    "preferredQualifications": string[]
  },
  "keywords": string[],        // 关键词提取
  "summary": string            // 摘要
}
```

### 简历与JD匹配度分析
**请求** `POST /api/v1/ai/match-analysis`
```json
{
  "resumeId": "string",        // 简历ID（或直接传content）
  "resumeContent": ResumeContent,  // 可选，与resumeId二选一
  "jdText": "string",          // 职位描述文本
  "jdStructured": JdStructured // 可选，如果已分析过
}
```

**响应** `200 OK`
```json
{
  "overallScore": number,      // 0-100
  "breakdown": {
    "skills": {
      "score": number,
      "matched": string[],     // 匹配的技能
      "missing": string[],     // 缺失的技能
      "suggestions": string[]  // 建议补充的技能
    },
    "experience": {
      "score": number,
      "alignment": string,     // "高" | "中" | "低"
      "gapAnalysis": string    // 经验差距分析
    },
    "education": {
      "score": number,
      "matched": boolean,
      "suggestions": string[]
    }
  },
  "improvementSuggestions": string[],  // 改进建议
  "optimizedSections": {       // 优化后的简历段落（示例）
    "summary": string,
    "workExperience": string[]
  }
}
```

### 简历优化生成
**请求** `POST /api/v1/ai/optimize-resume`
```json
{
  "resumeContent": ResumeContent,
  "jdText": "string",
  "focusAreas": string[],      // 可选，重点优化领域
```

**响应** `200 OK`
```json
{
  "optimizedContent": ResumeContent,
  "changes": {                 // 变更说明
    "summary": string,
    "workExperience": string[],
    "skills": string[]
  },
  "reasoning": string          // 优化理由
}
```

## 数据存储格式

### 数据库表结构（Prisma Schema）
```prisma
model User {
  id           String    @id @default(uuid())
  email        String    @unique
  phone        String?   @unique
  passwordHash String
  nickname     String
  avatar       String?
  modelPreference String @default("balanced")
  createdAt    DateTime  @default(now())
  updatedAt    DateTime  @updatedAt
  
  resumes      Resume[]
  sessions     Session[]
  logs         Log[]
}

model Session {
  id           String   @id @default(uuid())
  userId       String
  user         User     @relation(fields: [userId], references: [id])
  token        String   @unique
  expiresAt    DateTime
  createdAt    DateTime @default(now())
  
  @@index([userId])
  @@index([expiresAt])
}

model Resume {
  id          String   @id @default(uuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id])
  title       String
  description String?
  content     Json     // ResumeContent JSON
  fileUrl     String?
  fileType    String?
  isDefault   Boolean  @default(false)
  version     Int      @default(1)
  tags        String[]
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  
  versions    ResumeVersion[]
  
  @@index([userId])
  @@index([tags])
}

model ResumeVersion {
  id        String   @id @default(uuid())
  resumeId  String
  resume    Resume   @relation(fields: [resumeId], references: [id])
  version   Int
  content   Json
  note      String?
  createdAt DateTime @default(now())
  
  @@unique([resumeId, version])
}

model JdAnalysis {
  id        String   @id @default(uuid())
  userId    String
  user      User     @relation(fields: [userId], references: [id])
  jdText    String
  structured Json    // 结构化分析结果
  keywords  String[]
  createdAt DateTime @default(now())
  
  @@index([userId])
}

model MatchAnalysis {
  id           String   @id @default(uuid())
  userId       String
  user         User     @relation(fields: [userId], references: [id])
  resumeId     String
  resume       Resume   @relation(fields: [resumeId], references: [id])
  jdText       String
  jdAnalysisId String?
  jdAnalysis   JdAnalysis? @relation(fields: [jdAnalysisId], references: [id])
  score        Float
  breakdown    Json
  suggestions  String[]
  createdAt    DateTime @default(now())
  
  @@index([userId])
  @@index([resumeId])
}

model AiInteraction {
  id        String   @id @default(uuid())
  userId    String
  user      User     @relation(fields: [userId], references: [id])
  type      String   // 'jd_analysis', 'resume_optimization', 'greeting_generation'
  input     Json
  output    Json
  tokens    Int?
  cost      Float?
  model     String?
  duration  Int?     // 毫秒
  createdAt DateTime @default(now())
  
  @@index([userId])
  @@index([type])
  @@index([createdAt])
}

model Log {
  id        String   @id @default(uuid())
  userId    String?
  user      User?    @relation(fields: [userId], references: [id])
  action    String
  details   Json?
  ipAddress String?
  userAgent String?
  createdAt DateTime @default(now())
  
  @@index([userId])
  @@index([action])
  @@index([createdAt])
}
```
