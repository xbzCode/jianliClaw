## 各个模块的外部特性

### App Router 模块

#### 首页 (`app/page.tsx`)
- **功能**：展示产品价值主张、功能亮点、使用流程、用户案例、CTA按钮
- **外部依赖**：无认证要求，公开访问
- **技术特性**：服务端渲染（SSR），支持SEO

#### 认证路由组 (`app/(auth)/`)
- **登录页面** (`login/page.tsx`)
  - 表单：邮箱/手机号、密码
  - 提交后调用认证API，将JWT token存入sessionStorage
  - 跳转到工作台或原请求页面
- **注册页面** (`register/page.tsx`)
  - 表单：邮箱/手机号、密码、确认密码
  - 调用注册API，自动登录并跳转

#### 工作台路由组 (`app/(dashboard)/`)
- **简历工作台主页面** (`workspace/page.tsx`)
  - 布局：左侧导航，右侧主内容区
  - 集成子模块：职位解析、简历编辑、预览
  - 状态管理：Zustand store 管理当前简历、JD、匹配度数据
- **职位解析子页面** (`workspace/jd-parser/page.tsx`)
  - 输入：文本区域粘贴职位描述
  - 输出：结构化关键要求展示（技能、经验、学历等）
  - 调用后端JD解析API
- **简历编辑子页面** (`workspace/editor/page.tsx`)
  - 双栏布局：左侧Tiptap富文本编辑器，右侧实时预览
  - 功能：模板切换、版本保存、导出PDF
  - 数据存储：简历内容以JSON格式存储，通过API保存到后端
- **预览子页面** (`workspace/preview/page.tsx`)
  - 简历预览渲染，支持不同模板样式
  - 导出PDF按钮，调用后端PDF生成服务

#### 个人中心路由组 (`app/(dashboard)/personal/`)
- **简历库管理** (`resumes/page.tsx`)
  - 列表展示所有简历（原始版本、优化版本）
  - 操作：上传、下载、重命名、删除、设为默认
- **账户设置** (`settings/page.tsx`)
  - 表单：头像、昵称、密码修改
  - 模型偏好选择（Phase 2 功能）

#### 系统设置路由组 (`app/(dashboard)/admin/`)
- **API密钥配置**：表单管理后端API密钥
- **模型参数调节**：temperature、max_tokens等滑块控件
- **日志查看**：表格展示操作日志、模型调用日志

### 核心组件模块

#### UI 组件层 (`components/ui/`)
- **来源**：shadcn/ui 直接复制到项目中的组件
- **特性**：完全可控、无障碍支持、与Tailwind无缝集成
- **包含组件**：Button、Card、Dialog、Input、Select、Tabs等

#### 工作台专用组件 (`components/workspace/`)
- **JdParser**：职位描述输入与解析结果展示
- **ResumeEditor**：集成Tiptap的富文本编辑器，支持Markdown快捷键
- **MatchDashboard**：匹配度仪表盘，显示整体匹配度、关键词缺失、经验对齐建议
- **TemplateSelector**：模板选择器，3-5种简洁专业模板
- **PreviewPanel**：简历预览面板，实时渲染模板样式

#### 共享组件 (`components/shared/`)
- **Header**：顶部导航栏，包含用户菜单、主题切换
- **Sidebar**：侧边导航，根据路由高亮
- **ThemeToggle**：主题切换按钮（pure/tech主题）

### 状态管理模块

#### Zustand Stores (`lib/store/`)
- **auth-store**：管理用户登录状态、token、用户信息
- **theme-store**：管理当前主题（pure/tech），持久化到localStorage
- **resume-store**：管理当前编辑的简历内容、JD、匹配度数据、版本历史

#### TanStack Query (`lib/api/client.ts`)
- **功能**：服务端状态管理，数据获取、缓存、同步
- **配置**：统一错误处理、重试逻辑、请求拦截器自动添加Authorization头

### 样式与主题模块

#### Tailwind CSS (`tailwind.config.js`)
- **设计令牌**：扩展主题颜色、间距、断点、阴影、渐变
- **字体**：Inter为主字体，通过`next/font`加载

#### 主题系统 (`styles/theme.css`)
- **方案**：CSS变量 + `data-theme`属性
- **切换**：通过修改`<html data-theme="pure|tech">`动态切换
- **暗色模式**：由主题变量控制，可选支持

### 工具与工具函数模块

#### API客户端 (`lib/api/`)
- **统一封装**：基于原生`fetch`，错误处理统一
- **模块划分**：auth、resume、ai等领域的API函数

#### 表单与校验 (`lib/utils/validation.ts`)
- **方案**：React Hook Form + zod
- **集成**：`@hookform/resolvers/zod`实现表单校验

#### 富文本编辑器 (`components/workspace/ResumeEditor.tsx`)
- **核心**：Tiptap + ProseMirror
- **扩展**：`@tiptap/starter-kit`、`@tiptap/extension-placeholder`
- **功能**：富文本编辑、Markdown语法快捷键、实时预览

### 性能优化模块

#### Next.js 优化
- **图片**：使用`next/image`自动优化
- **字体**：`next/font`自托管与预加载
- **代码分割**：App Router自动分割 + dynamic导入
- **SEO**：`generateMetadata`生成页面元数据

#### 动画与微交互
- **CSS动画**：Tailwind内置`animate-*`类
- **复杂动画**：Framer Motion（页面切换、拖拽、手势）

### 测试模块

#### 单元/组件测试
- **框架**：Vitest + React Testing Library
- **范围**：核心组件、工具函数、hooks

#### E2E测试
- **框架**：Playwright
- **场景**：用户注册、登录、简历编辑、导出流程

### 部署配置

#### 环境变量
- **文件**：`.env.local`、`.env.production`
- **内容**：API基础URL、Next.js配置等

#### 构建与部署
- **平台**：自托管Node.js
- **流程**：Docker容器化，通过CI/CD自动部署

## 技术栈总结

- **核心框架**：React 19 + Next.js 16 (App Router) + TypeScript
- **UI组件**：shadcn/ui + Lucide Icons
- **状态管理**：Zustand (客户端)
- **表单与校验**：React Hook Form + zod
- **样式**：Tailwind CSS 4
- **HTTP客户端**：Axios
